# Product Spec

## Product

Lead.AI Lead Scoring API

## Role

Predictive lead scoring and qualification API.

## Value Proposition

A JSON API that scores leads, explains priority factors, and helps teams focus follow-up on the best opportunities.

## Problem

Businesses do not know which leads deserve priority follow-up.

## Target Users

- Sales teams
- CRM builders
- Lead generation agencies
- Small business operators
- Growth teams

## Core Features

- Lead scoring endpoint
- Lead qualification rules
- AI-generated lead summary
- Risk/opportunity score
- JSON API
- Input validation
- API documentation
- Test examples

## MVP Scope

The MVP should prove one practical workflow before expanding into a full product.

First valuable demo: Create Pydantic schemas, deterministic scoring rules, and example API responses.

## Out Of Scope For MVP

- Production claims.
- Real customer data.
- Complex multi-tenant enterprise controls.
- Unsupported accuracy claims.
- Paid billing flows unless explicitly required for the first demo.

## Success Metrics

- A visitor understands the product in under 10 seconds.
- The primary workflow can be demonstrated with safe sample data.
- Setup and security expectations are documented.
- AI outputs include limitations, explanations, or review guidance where relevant.
